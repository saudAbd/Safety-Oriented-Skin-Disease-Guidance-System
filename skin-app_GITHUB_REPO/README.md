# Safety-Oriented Edge Dermatology Guidance System

This repository contains code, documentation, and lightweight evaluation artifacts for a hierarchical dermatology guidance pipeline designed for edge/mobile deployment.

Raw datasets and trained model checkpoints are not included due to size and licensing constraints.

## Main pipeline

1. Gatekeeper: normal/non-skin vs abnormal skin
2. Router: lesion vs rash
3. Lesion safety screen: lower-risk vs suspicious lesion
4. Rash specialist: acne vs eczema vs fungal
5. Acne severity: normal/mild/moderate/severe
